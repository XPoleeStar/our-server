1. Общие положения

    Настоящее Пользовательское соглашение (далее — Соглашение) регулирует отношения между оператором учебного проекта «Система автоматического учета посещаемости на основе QR-кодов» (далее — Сервис) и лицами, использующими Сервис (далее — Пользователи).

    Сервис разработан в учебных целях в рамках образовательного проекта. Использование Сервиса означает ознакомление Пользователя с условиями настоящего Соглашения и их принятие.

  2. Описание Сервиса
    1. Сервис предназначен для автоматизированного учета посещаемости учебных занятий с помощью QR-кодов.
    2. Сервис предоставляет студентам и преподавателям возможность авторизации и использования функций в соответствии с их ролями.
    3. Для учета посещаемости используется сканирование и считывание QR-кодов.
    4. Сервис предоставляется «как есть». Разработчики не гарантируют бесперебойную работу, отсутствие ошибок и постоянную доступность Сервиса.
  3. Права и обязанности Пользователя
    1. Пользователь обязуется использовать Сервис только в законных целях.
    2. Пользователь обязан сохранять конфиденциальность своих учетных данных и не передавать их третьим лицам.
    3. Пользователю запрещается:
      • предпринимать попытки взлома или нарушения работы Сервиса;
      • использовать чужие учетные записи;
      • пытаться обходить ограничения и механизмы учета посещаемости.
    4. Пользователь вправе обращаться к ответственному лицу по вопросам работы Сервиса и обработки своих данных.
  4. Обработка персональных данных
    1. Сервис обрабатывает данные, необходимые для авторизации пользователей и учета посещаемости:
      • логин и хеш пароля;
      • ФИО и учебную группу студентов;
      • ФИО и учетные данные преподавателей;
      • идентификатор браузера, сохраняемый в IndexedDB;
      • сведения о посещаемости, включая дату и время регистрации.
    2. Данные используются исключительно для:
      • регистрации и авторизации пользователей;
      • идентификации браузера и устройства в рамках работы Сервиса;
      • учета и отображения посещаемости;
      • предоставления преподавателям доступа к информации о занятиях и посещаемости.
    3. Исходные пароли пользователей не хранятся. В базе данных сохраняются их криптографические хеши.
    4. Доступ к данным предоставляется только в пределах, необходимых для выполнения функций Сервиса.
    5. Данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством или необходимых для обеспечения работы Сервиса на законных основаниях.
    6. Данные хранятся в течение периода, необходимого для достижения целей обработки, после чего удаляются или обезличиваются, если иное не предусмотрено законодательством.
    7. Пользователь вправе обратиться к ответственному лицу для получения информации об обработке своих данных, исправления неточных сведений или их удаления при наличии законных оснований.
  5. Ограничение ответственности
    1. Сервис является учебным прототипом и может содержать технические ошибки и ограничения.
    2. Разработчики не гарантируют сохранность данных и бесперебойную работу Сервиса.
    3. Ограничение ответственности не распространяется на случаи, когда ответственность не может быть исключена или ограничена в соответствии с законодательством.
  6. Изменение условий
    1. Разработчики оставляют за собой право изменять функциональность Сервиса и условия настоящего Соглашения.
    2. Актуальная версия Соглашения размещается в Сервисе.
    3. Изменения вступают в силу с момента публикации, если в них не указано иное.
